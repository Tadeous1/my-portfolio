MY ANALYTICS PROCESS

From a question to a recommendation.

A good dashboard is the visible end of a careful chain of decisions. I make each stage clear so the result can be reviewed, repeated, and trusted.

01

Ask

Define the decision and the question the data should answer.

02

Collect

Locate the real source, scope, fields, and response window.

03

Clean

Check duplicates, missing values, categories, units, and assumptions.

04

Analyze

Summarize patterns, compare groups, and test the useful questions.

05

Visualize

Build charts that make the insight and limitation visible.
