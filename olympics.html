READOUT

Country totals are not the same as athlete counts

The dashboard separates medal concentration from sport participation so the visitor can see both performance outcomes and the scale of participation.

This is a public-data demonstration based on the linked Rio 2016 dataset, not a claim that the original portfolio notebook used this exact file.

METHOD & LIMITATIONS

How this dashboard was built

Source. Public Rio 2016 athlete and medal CSV from DataHub, cross-referenced with the official IOC results database for context.

Processing. Grouped medal columns by nationality, counted athlete entries by sport, and summarized the male/female entry mix.

Limitations. Medal totals are dataset aggregates and should be interpreted as an exploratory view, not as a replacement for the IOC’s official results database.
