METHOD & LIMITATIONS

How this dashboard was built

Source. Supplied file `LAUTECH_Student_Snack_Preferences_Cleaned_3500.csv` with 3,500 records and 13 columns.

Processing. Checked duplicate Student_ID values, blank cells, explicit Unknown values, numeric ranges, and categorical distributions before calculating the dashboard summaries.

Limitations. The file is described as cleaned, but its collection instrument, response window, and sampling method were not supplied, so the dashboard does not claim population-wide representativeness.

Source file supplied for this portfolio case study.No synthetic responses were added.
